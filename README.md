# 书游引擎 · BookPlay

> 阅读为主、影响为辅的互动小说网页应用。导入一本 txt，正常阅读原文；随时插入你的行动，影响剧情走向 —— **原文永不改写，影响用旁注/支线呈现**。

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## ✨ 特性

- 📖 **导入即读**：拖入 txt 自动分章（UTF-8 / GBK 都能识别），看书 0 消耗
- 🎭 **开局选角色**：AI 分析书籍类型、生成符合世界观的 3 个身份；锁定唯一 PC，换角色开新存档
- ⚡ **0 token 原则**：看书、简单/中等行动走本地规则，只有复杂行动才调 AI（带缓存）
- 🧠 **影响层**：NPC 记忆、关系、主线偏移度，结构化存本地，原文永不改动
- 📌 **旁注 + 影响面板**：行动锚定到正文，点图标在侧边面板看影响
- 📋 **成长面板**：档案 / 能力 / 势力 / 履历 / 关系 / 偏移 / 系统 七维侧边栏
- 🎮 **系统面板**：经验值、等级、点数兑换（全本地 0 token）
- 💾 **存档点**：手动存档 + 每章自动存档，玩崩了随时读档回退
- 💰 **消耗控制**：显示 token 与费用、每日预算、相同行动走缓存
- 🔒 **隐私**：数据存浏览器本地，服务器零存储，API Key 不上传
- 🔍 **正文搜索**：全文搜索，点结果跳转章节
- 📊 **阅读统计**：章节进度、行动次数、偏移度趋势曲线
- 🎧 **听书模式**：浏览器朗读原文，倍速 / 定时 / 连播
- 🎬 **多结局 + 报告 + 分享卡片**：判定结局、生成报告、一键出图分享
- 🎭 **剧本杀（单人）**：AI 扮演角色，搜证对话指认真凶
- 🎯 **名场面 / 意难平 / 回响 / 沉浸**：读得更沉浸、更有回音
- ✏️ **划线批注 + 书签**：边读边划、标记章节
- ⏱️ **阅读时长 / 目标打卡**：统计阅读时长，设每日目标
- 🕸️ **关系图谱 / 成就 / 结局图鉴**：可视化关系、收集成就和结局
- 📚 **预设剧本库 / 支线任务板**：没书也能玩，自己接支线
- 🎭 **AI 反馈风格 / 时间线 / 分享卡多主题**：更个性化
- 📱 **多端适配**：电脑手机都能用，暗色模式，各自数据独立
- 📲 **可安装成 App（PWA）**：添加到主屏幕，手机端数据不易被清理
- 🚀 **静态部署**：一键部署 Vercel / GitHub Pages / Netlify

## 🎮 完整使用说明

### 一、这是什么

一个「**阅读为主、影响为辅**」的互动小说网页应用。核心玩法：**导入一本 txt 小说，正常读原文；读到关键时刻，输入你的行动去改变剧情——但原文永远不改，你的影响以「旁注」和「影响面板」的形式呈现。**

它有一个关键设计：**服务器只放静态网页，大脑（数据 + 逻辑）全在你自己的浏览器里。** 所以天生具备：

- **看书 0 消耗**：只有「复杂行动」才调用 AI，其余全走本地规则；
- **数据本地化**：书、存档、NPC 记忆、数值都存在你浏览器里，谁打开谁各存各的、互不干扰；
- **API Key 不上传**：填在你自己的浏览器里，服务器不保存。

### 二、核心思路

| 概念 | 含义 |
|---|---|
| **原文永不改写** | 你导入的小说原文一字不动，你的选择不会篡改正文 |
| **行动（旁注）** | 选中一句话 → 输入你想做的事 → 那句话末尾长出一个图标，点开看结果 |
| **主线偏移度** | 0~1 的数值，衡量你对剧情「改了多少」，越高越偏离原著 |
| **NPC 记忆** | 每个角色一张关系卡：态度、信任度、关系变化史 |

### 三、快速上手（三步）

1. **导入小说**：把 `.txt` 拖进页面（或点导入），自动按「第X章 / Chapter X」分章（UTF-8 / GBK 都能识别）。支持多本书，顶部书架切换。没带书也能玩——导入区有 3 篇原创预设剧本（《雨夜客栈》悬疑、《深宫棋局》宫斗、《江湖夜雨》武侠），点一下直接开始。
2. **开局选角色**：导入后自动进「开局」——配了 AI 会自动分析书籍类型生成 3 个符合世界观的身份；没配 AI 用通用模板（废柴逆袭 / 世家天才 / 市井白手）。起个名字 →「开始游玩」；想换角色 =「＋新存档」。
3. **阅读 + 行动**：「📑 目录」看章节，「←/→」（键盘方向键也能）翻章；底部输入框输入行动、回车提交——这就是「玩」的核心。

### 四、核心玩法：插入行动

行动分三级，消耗不同：

| 级别 | 例子 | 处理方式 | 消耗 |
|---|---|---|---|
| 简单 | 打听、观察、闲聊、移动 | 本地规则秒回 | 0 token |
| 中等 | 结交、试探、谈判 | 本地规则 + 更新关系 | 0 token |
| 复杂 | 建势力、干预主线、改变关键关系 | 调 AI 判断 | 按次计费 |

**旁注玩法**：选中正文某句话 → 输入行动提交 → 那句话末尾长出图标（💡 简单/中等，📈 复杂）→ 点图标右侧弹出「影响面板」，高亮显示这次行动的结果。

**影响体现在哪**：简单 +0 偏移、中等 +0.02、复杂 +0.1，从「自由支线」一路到「剧情事件拉回」；NPC 记忆记录下你说过做过的事。

### 五、成长面板（七维）

点「📋 角色」打开侧栏，7 个标签页实时更新：**档案 / 能力 / 势力 / 履历 / 关系 / 偏移 / 系统**。「关系」页顶部还有一张**关系图谱**（你居中、NPC 围圈，连线按信任度绿/黄/红）。

### 六、系统面板（经验 / 点数 / 商城 / 意难平）

- **经验**：读新章节 +5、简单 +2、中等 +8、复杂 +20（全本地 0 token）；100 经验升 1 级，每级送 10 点数；
- **商城**：按书籍类型动态生成（修仙→丹药功法、权谋→密信暗卫…），分初级/中级/高级/顶级四档；
- **意难平清单**：记下最多 3 件「最想改变的事」，阅读时置顶提醒；
- **支线任务板**：自己接支线、勾选完成；
- **约束**：偏移度 ≥0.8 时拒绝兑换（不能破坏主线）。

### 七、存档点（手动 + 自动）

每翻到新章自动存档一次（保留最近 3 个）；也可手动命名存档。玩崩了（比如偏移度太高）点旧存档「读档」回退。

### 八、搜索 · 统计 · 结局 · 报告 · 分享

- 🔍 **搜索**：全文搜当前书，点结果跳章节；
- 📊 **统计**：章节进度 / 行动次数 / 关系数 / 等级 / 点数 / 偏移度趋势曲线（虚线标 0.3 / 0.6 / 0.8 分级线）；
- 🎬 **多结局**：按偏移度判定（原著 / 改变 / 颠覆 / 世界反噬）4 种；
- 📋 **玩后报告**：一键生成 Markdown 报告；
- 🖼️ **分享卡片**：生成 PNG 图片，4 套主题；
- ⏱️ **阅读时长 / 目标打卡**：自动计时，设每日目标，看进度条、连续打卡 🔥 和本周柱状图；
- 🏅 **成就 + 结局图鉴**：8 个成就、4 个结局，达成自动点亮。

### 九、更多阅读玩法

🕶 **沉浸模式**（隐藏 UI 只看正文）· 🎯 **名场面**（读到退婚/决斗/大比等关键词提示「可干预」）· 📌 **影响回响**（早期行动在后续章节「回响」）· ✏️ **划线批注**（私人笔记，不改剧情）· 🔖 **书签** · 🎧 **听书**（朗读原文，倍速/定时/连播/换音色，免费 0 token）。

### 十、剧本杀（单人）

顶栏「🎭 剧本杀」→ 选剧本《风雪庄园凶案》→ 选角色（各有秘密和隐藏任务）→ 搜证 → 盘问 AI 扮演的角色（Ta 会隐瞒、撒谎）→ 指认真凶看对错。

### 十一、接入 AI

「复杂行动」和「开局身份生成」需要 AI。右上角 ⚙️ 有 4 个一键切换：🖥️ **本地 Ollama**（免费）/ ☁️ **DeepSeek**（云，填 Key）/ 🔧 **自定义** / ⛔ **关闭**。还能选「反馈风格」（原著风/轻松风/严肃风/吐槽风）改变 AI 语气。

> 本地 Ollama 只在本机 `localhost` 有效；部署到网上的网址用 DeepSeek。

### 十二、导出 / 换设备 / 清数据

- **导出**：档案（Markdown）/ 影响线（Markdown）/ 存档备份（JSON）；
- **换设备**：新设备先导入原 txt → ⚙️「导入存档备份」恢复；
- **清数据**：⚙️ → 数据管理 →「清理垃圾数据」或「清除所有数据」。

### 十三、安装成 App（PWA）—— 手机数据不丢的关键

**为什么**：手机浏览器（尤其 Edge）会在关标签/后台清理时清掉本地数据，存档重开就丢。装成 App 后浏览器会把它当常驻应用，并自动申请「持久化存储」，基本解决。

**怎么装**：浏览器打开网址 → Android Edge/Chrome 右下「···」→「添加到主屏幕」；iPhone Safari 底部「分享」→「添加到主屏幕」→ **之后从主屏幕新图标进**。

> ⚠️ 换浏览器、手动「清除浏览器数据」或用系统清理工具，仍可能清掉数据。重要进度记得用「导出存档」备份。

### 十四、数据隐私

所有数据存浏览器 IndexedDB；API Key 存 localStorage；服务器零存储；转发给别人用也花不到你的钱、碰不到你的数据。

## 🛠 技术栈

Next.js 14 (App Router) · TypeScript · Tailwind CSS · Zustand · Dexie.js (IndexedDB) · OpenAI 兼容 API · PWA (manifest + Service Worker)

## 🚀 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000，导入 `samples/示例小说.txt` 即可体验完整流程。

## 🤖 配置 AI

「复杂行动」和「开局身份生成」需要 AI。点右上角 ⚙️，顶部有 **4 个「AI 来源」按钮一键切换**：🖥️ 本地 Ollama（免费）/ ☁️ DeepSeek（云）/ 🔧 自定义 / ⛔ 关闭 AI，切换时自动填充接口地址和模型，并显示当前状态（本地免费 / 云计费 / 已关闭）。

**本地 Ollama（免费、无需 Key）**

1. 安装 [Ollama](https://ollama.com)，运行 `ollama pull qwen2.5:7b`
2. ⚙️ 点「本地 Ollama」→ 保存

**DeepSeek（云服务）**

1. 到 [platform.deepseek.com](https://platform.deepseek.com) 申请 API Key
2. ⚙️ 点「DeepSeek」→ 填 Key → 保存

> ⚠️ API Key 只存在你浏览器 localStorage，**绝不上传服务器**。部分云服务商禁止浏览器直连（CORS 限制），如遇此问题请改用本地 Ollama 或自建代理。
>
> ℹ️ 隐私说明：用**本地 Ollama** 时 AI 完全在你的电脑上跑、不出本机；用**云端 DeepSeek** 时，「复杂行动」和「开局身份分析」会把相关的小说上下文 + 你的行动发给 DeepSeek 服务商做判断（这是实现 AI 功能所必需的）。

## 📦 部署

构建静态文件：

```bash
npm run build   # 产物在 out/ 目录
```

### Vercel

把仓库推送到 GitHub → 在 [vercel.com](https://vercel.com) 导入仓库 → 自动识别 Next.js 并部署（构建命令 `npm run build`，输出目录 `out`）。

### Netlify

Netlify 导入仓库，构建命令 `npm run build`，发布目录 `out`（已配好 [netlify.toml](netlify.toml)）。

### GitHub Pages

已配好自动化部署（[.github/workflows/deploy.yml](.github/workflows/deploy.yml)）：**push 到 `main` 分支即自动构建并部署**。子路径 `/book-play/` 的 `basePath` 由工作流通过 `GITHUB_PAGES=true` 自动启用，无需手动改配置。

> 部署到网上后，**每个访客的数据只存在自己的浏览器里**，服务器不保存任何用户数据。

## 🔒 数据与隐私

- 所有数据存浏览器 IndexedDB（Dexie.js），服务器零存储
- API Key 存浏览器 localStorage，绝不上传
- **AI 上下文**：本地 Ollama 完全不出本机；云端 DeepSeek 会把「复杂行动 / 开局分析」的相关上下文发给其服务商
- 自动清理无主的孤儿数据，保持数据干净
- 「⚙️ 设置 → 数据管理」可随时**清除所有数据**

## 📁 项目结构

```
src/
  lib/        # db(IndexedDB) / parser(分章) / actions(本地规则) / ai(调模型)
              # settings(配置) / export(导入导出) / system(经验兑换) / cache(AI缓存) / store(状态)
  components/ # BookImporter / Reader / CharacterCreator / ActionPanel
              # CharacterPanel / ImpactPanel / TocPanel / SavePanel / SettingsModal
  app/        # 页面与布局
public/       # manifest.json / sw.js / icons/（PWA 相关）
scripts/      # generate-icons.mjs（生成 PWA 图标）
```
